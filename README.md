# Vehicle Management System

An Android application developed using **Kotlin** and **SQLite** to manage vehicle records easily.

## About the Project

The Vehicle Management System is designed to store and manage vehicle information. Users can perform basic CRUD operations (Create, Read, Update, Delete).

## Features

- Add new vehicle records
- View vehicle details
- Update existing vehicle information
- Delete vehicle records
- Store vehicle insurance details
- Local data storage using SQLite

## Technologies Used

- **Language:** Kotlin
- **Platform:** Android
- **Database:** SQLite
- **IDE:** Android Studio

## Installation

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an Android device or emulator.
